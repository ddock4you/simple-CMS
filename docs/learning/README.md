# 학습 문서

CMS 개발과 병행하는 학습 + 면접 준비 문서 모음.
각 개발 주제에 대해 **사전학습**(개발 전)과 **학습정리**(개발 후) 두 종류의 문서가 생성된다.

## 사용법

```
/pre-learn     # 개발 시작 전 실행 → 사전학습 문서 자동 생성
/post-learn    # 개발 완료 후 실행 → 학습정리 문서 자동 생성
```

인자 없이 실행하면 현재 대화 컨텍스트에서 주제를 자동 파악한다.

## 문서 구조

### 사전학습 (`{주제}-사전학습.md`)

- 핵심 개념 + 동작 원리
- 레거시 ↔ 모던 대조표
- 구현 시 주의할 점
- 설명 가능 체크리스트

### 학습정리 (`{주제}-학습정리.md`)

- 구현 요약 + 프로젝트 코드 기반 설명
- 동작 원리 심화
- 레거시 경험 연결
- 면접 예상 질문 & 답변 (꼬리 질문 포함)
- 트러블슈팅 로그
- 한 줄 요약 카드 (면접 직전 복습용)
